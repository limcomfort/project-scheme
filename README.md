# Project Scheme (Автосервис)

Реализация UML-схемы предметной области "Автосервис" на TypeScript
с соблюдением принципов SOLID.

## 📋 Описание

Проект моделирует работу автосервиса:
- **Владелец** покупает/продаёт автомобиль
- **Автомобиль** состоит из двигателя и колёс
- **Механик** принимает заказы и выполняет ремонт
- **Заказ** проходит стадии: открыт → оплачен → закрыт

## 🧩 Принципы SOLID

| Принцип | Реализация |
|---------|-----------|
| **S** — Single Responsibility | Каждый класс отвечает за одну сущность |
| **O** — Open/Closed | Новые типы двигателей/колёс добавляются без изменения `Car` |
| **L** — Liskov Substitution | Любая реализация `IEngine` подходит для `Car` |
| **I** — Interface Segregation | Маленькие интерфейсы: `IEngine`, `IWheel`, `IOrder` |
| **D** — Dependency Inversion | `Car` зависит от абстракций, а не от конкретных классов |
